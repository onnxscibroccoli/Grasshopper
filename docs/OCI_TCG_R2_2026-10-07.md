## Contract OCI-TCG-NETWORK-20261007-02

rootless Podman, loopback published ports 15555/15912/16082. Repository:
onnxscibroccoli/Grasshopper, branch feat/oci-tcg-r2-20261007.

Root cause: Android-x86 renamed the virtual NIC to wifi_eth and did not
assign IPv4. After assigning 10.0.2.15/24, Android policy routing still
ended in an unreachable rule before consulting the main route table.
Adding a priority 18000 main-table rule restored connectivity without
changing firewall rules or disabling ADB authentication.

The launcher now supports opt-in CLOUD_ANDROID_STATIC_NETWORK=1. Its guest
helper verifies the fixed QEMU NIC MAC, waits at most 120 seconds, configures
the address and route, and avoids replacing an existing address or adding
a duplicate rule. Three regression tests cover renamed NIC, repeated setup,
and rejection of an unknown NIC identity. A live first attempt exposed
that replacing an active address could interrupt ADB; this was corrected.
A later guest restart established authenticated ADB without console repair.

The development runtime now uses CLOUD_ANDROID_TCG_THREADS=multi,
CLOUD_ANDROID_CPUS=2, CLOUD_ANDROID_MEMORY_MB=2048, scheduling nice 10, and
CLOUD_ANDROID_BOOT_DEX_FILTER=extract. The dex filter is opt-in; the default
image policy remains unchanged. Android accepted the property and emitted
an actual dex2oat --compiler-filter=extract startup job before the restart.

measurement. TCG warns that two requested CPU feature bits are unavailable.
