## Rebuild and recovery

Build scripts/cloud-android/Containerfile.tcg with Podman. Mount this source read-only with an appropriate SELinux label, the existing noVNC viewer read-only, and a separate writable persistent state directory. Generate a development ADB operator key in the state directory. Set CLOUD_ANDROID_STATE_DIR, CLOUD_ANDROID_ADB_PUBLIC_KEY_FILE, CLOUD_ANDROID_WEB_ROOT, CLOUD_ANDROID_MEMORY_MB=1536, CLOUD_ANDROID_CPUS=1 and CLOUD_ANDROID_ACCELERATOR=tcg before invoking the canonical persistent-device.sh start. Publish only loopback ports. The base image digest is pinned; APK/Python transitive package resolution is not fully locked, so clean-host reproducibility is still unproven.

To stop this isolated guest without deleting state:

    podman --root /srv/grasshopper/android/development/qemu-container-store stop grasshopper-android-tcg

Preserve data.img and the operator key for recovery. Do not remove state or reset existing worktrees. Rootless CPU cgroup delegation is unavailable on this user session; guest RAM and vCPU count constrain this development guest, but are not a complete host CPU/memory enforcement mechanism.
